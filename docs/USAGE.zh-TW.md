# 日常操作與功能

本指南對應 `0.2.0-rc.56-tw-scroll`。按鍵名稱採裝置畫面上的「上、下、確定」；短按與長按有不同用途。

## 首頁與應用程式選單

| 畫面 | 操作 | 結果 |
| --- | --- | --- |
| 首頁 | 短按確定 | 開啟應用程式選單 |
| 首頁 | 短按上鍵 | 開啟／關閉隨身名片；未上傳名片時保留原有天氣刷新行為 |
| 首頁 | 短按下鍵 | 切換操作提示、網路與天氣等底部詳情 |
| 首頁 | 長按下鍵 | 開啟「手機設定」 |
| 首頁 | 長按上鍵 | 切換底部圖案；顯示名片時不生效 |
| 名片畫面 | 上／下鍵 | 多張名片前後翻頁 |
| 名片畫面 | 短按確定 | 收起名片回到首頁 |
| 應用程式選單 | 上／下鍵 | 選擇應用程式 |
| 應用程式選單 | 短按確定 | 開啟選中的應用程式 |
| 一般應用程式 | 長按確定 | 返回選單；從選單再長按確定返回首頁 |

首頁切到網路／天氣詳情時，短按確定可依該頁提示要求更新天氣，不一定直接開啟選單。手動刷新有間隔限制；請以當下畫面提示為準。

## Wi-Fi 與手機設定

裝置使用 2.4 GHz Wi-Fi。手機或電腦使用同一路由器的 5 GHz Wi-Fi／網線，也可以操作設定或使用隨身語音，前提是網路允許裝置互通。

### 第一次設定

1. 依裝置畫面開啟「手機設定」，或從首頁長按下鍵進入。
2. 手機連接畫面顯示的 `Passport-WiFi-…` 熱點；尾碼每台不同。
3. 若手機提示此網路沒有網際網路，選擇繼續使用。
4. 瀏覽器手動開啟 `http://192.168.4.1`。
5. 選擇家中 2.4 GHz Wi-Fi，輸入密碼並依網頁完成連線。
6. 填寫個人資料、選擇城市，按需要上傳頭像和名片，再完成儲存。
7. 設定完成後，手機切回平時使用的網路；裝置回到首頁使用已儲存的 Wi-Fi。

裝置設定頁本身由裝置提供，不必先有網際網路。設定時熱點只用於連網與資料編輯；收聽電臺、天氣與 AI 服務仍需要路由器的對外連線。

### 已設定過，只改資料

在「手機設定」網頁可使用既有 Wi-Fi，或選擇「暫不聯網，只修改個人資料」。無須為了換照片重新輸入所有網路設定。編輯後要完成儲存，僅選好圖片或改動輸入框不會立即寫入。

## 個人資料、彩色頭像與名片

### 姓名、簽名與城市

在手機設定頁的個人資料步驟編輯姓名、個性簽名、地址與城市。城市和經緯度供天氣使用；這版收音機維持固定十臺，不會因為改城市而重建清單。

首頁「想說的話／個性簽名」超出欄位寬度時，會以橫向循環跑馬燈展示完整內容；能放得下的短文字維持靜止。是否捲動依實際文字寬度判定，不是固定五個字的限制。姓名等其他欄位仍可能以省略號顯示。

姓名及簽名仍有輸入長度與 UTF-8 位元組數限制，過長時網頁會要求縮短；跑馬燈不會改變已儲存的內容。

### 選擇單色或彩色頭像

進入「首頁人像」後，直接選擇 **單色** 或 **彩色**，完成儲存後生效。這個選項不需要先選新圖片：

- 已儲存彩色照片：可直接切換顯示方式，重新開啟設定頁會讀回上次選擇。
- 選擇單色：首頁用目前主題的單色調色盤顯示，原始照片色彩仍會保留。
- 再切回彩色：恢復原照片色彩，不必重新選檔或裁切。
- 舊格式單色頭像：頁面會說明需要原始彩色照片，並停用無法還原的彩色選項；選擇新彩色照片後即可使用。

更換照片時，選擇原始圖片、調整取景與明暗，確認預覽後儲存。新圖片無論選擇單色或彩色顯示，都保留原始配色供日後切換。

儲存尺寸為 **96 × 138 像素**，使用最多 **255 種照片色彩加透明背景**。這是裝置記憶體範圍內的索引色彩，不是原始照片解析度或無損全彩。先前的點陣、平塗與混合格式仍可讀取；它們沒有保留原始 RGB 色彩，不能準確還原照片原色。

### 隨身名片

最多保存 **6 張**名片／QR code 圖片。網頁會縮放成 **240 × 320** 的彩色 JPEG，每張上限 **24 KB**。完成儲存前可替換、移除及排序；首頁短按上鍵開啟名片，上下翻頁，短按確定返回。

QR code 請保留四周白邊，不要把重要區域裁掉。選取圖片不代表已儲存，需完成設定流程。

## 收音機

開啟「城市收音機」後，裝置會在 Wi-Fi 就緒時開始連接，並使用上次保存的選臺位置。清單固定為 [README 的十個電臺](../README.md#收音機內建哪十臺)。

| 操作 | 功能 |
| --- | --- |
| 短按上鍵 | 下一臺 |
| 短按下鍵 | 上一臺 |
| 短按確定 | 播放／暫停 |
| 長按上鍵 | 增加音量 |
| 長按下鍵 | 降低音量 |
| 長按確定 | 返回應用程式選單 |

音量與系統設定共用。電臺不可用時，播放器會重試，連續失敗可能跳到下一臺；這不代表固定清單已被改掉。「連線中」「緩衝中」「播放中」是不同階段，Wi-Fi 圖示有訊號也不代表電臺伺服器一定可連。

## 設定與恢復預設

設定頁提供音量、螢幕亮度、自動熄屏、外觀主題、按鍵音效、手機設定、恢復預設、無線網路，以及網路與時間資訊。

- 音量：短按確定進入調整，用上下鍵增減，再按確定完成。
- 螢幕亮度：循環 20%、40%、60%、80%、100%。
- 自動熄屏：常亮，或 15、30、60、120、300 秒。
- 外觀主題：經典綠、旅行儀器、畫素白、霓虹黑。
- 恢復預設：需再次按確定確認，恢復音量／亮度 80%、60 秒熄屏、經典綠與開啟按鍵音效。

**「恢復預設」只恢復系統設定，保留 Wi-Fi 與個人資料；它不是整片 Flash 清除。** 自動熄屏是顯示管理，也不要與完全斷電或清除資料混為一談。

### 三種語音／電腦功能怎麼分

| 功能 | 做什麼 | 另需什麼 |
| --- | --- | --- |
| 隨身 AI 語音 | 把裝置當成電腦的無線麥克風與語音快捷鍵 | [原作者的電腦轉發器](https://github.com/manchunx7-bit/folo-ai-passport-voice)；Mac 使用 BlackHole 2ch，Windows 使用 VB-CABLE，另配輸入法 |
| 小智 AI | 直接用裝置與語音助理對話 | [小智服務](https://xiaozhi.me)與裝置設定 |
| 小智 MCP 控制電腦 | 讓同一個小智智能體呼叫電腦工具 | 帳號後台的 MCP 接入點，加上獨立電腦橋接／工具服務，例如[官方 MCP 範例](https://github.com/78/mcp-calculator) |

這份韌體原始碼不包含 Mac／Windows 桌面安裝器。單純安裝韌體不會把 USB 變成電腦麥克風，也不會自動讓小智取得電腦控制能力。裝置端的小智 IoT 工具與後台綁定的電腦 MCP 工具是不同路徑。

### 隨身語音按鍵

按住上鍵開始，等輸入法語音介面出現後說話；放開結束，確認文字穩定後短按下鍵送出 Enter。先在空白文稿測試，因為 Enter 在聊天軟體裡可能直接送出訊息。

快捷鍵與 `hold`／`tap` 模式須符合實際輸入法設定，F9 不是所有輸入法的通用預設。Mac 轉發器出口及輸入法音源都應使用 BlackHole 2ch；一般系統輸出仍保留原本喇叭或耳機。安裝、系統授權及實際說話驗收請依[原作者的 Mac 指南](https://github.com/manchunx7-bit/folo-ai-passport-voice/blob/main/macos/README.zh-CN.md)進行。

隨身語音電腦端的診斷通過，不等於已驗證真正說話能出字。本 fork 的實機驗證也沒有承諾所有輸入法、Muse 帳號或小智帳號都已完成端到端測試。

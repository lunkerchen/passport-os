AI 隨身語音電腦語音輸入

裝置與電腦連線同一 Wi-Fi。下載電腦端完整包，安裝虛擬音效卡和微信輸入法（也可用其他支援快捷鍵的語音輸入法），再啟動語音轉發器。

電腦輸入裝置選 CABLE Output；轉發器輸出選 CABLE Input。輸入法快捷鍵與轉發器保持一致。裝置上鍵按住說話、鬆開結束，下鍵傳送回車。

AI 隨身語音專案、下載與完整教程

設定頁可以離線使用。開啟 GitHub 教程前，先完成設定並將手機切回能上網的網路；以後可從裝置“設定 → 手機設定”再次檢視入口。

選圖沒有反應？從檔案選擇

備用入口使用檔案選擇器。請選 JPEG 或 PNG 圖片；若圖片只在相簿中，先儲存到“檔案”。如果兩個入口都打不開，保持連線裝置熱點，在系統 Safari／Chrome 位址列輸入 http://192.168.4.1；也可用電腦連線熱點後上傳。

裝置效果

彩色隨身名片最多 6 張

最多儲存 6 張名片或二維碼。首頁按上鍵開啟，上下鍵翻頁，確定返回。推薦 3:4 比例，二維碼周圍請保留白邊。

在檔案選擇器中長按一張圖片進入多選，再勾選其它圖片並確認。可選擇 JPEG、PNG 或 WebP 圖片。

改用相簿選擇

如果相簿只能單選，請使用上面的檔案多選入口；可先把圖片儲存到手機“檔案”。在系統瀏覽器位址列輸入 http://192.168.4.1 開啟設定頁，可避免部分內建瀏覽器的限制。

選圖後會逐張縮放至 240 × 320 並壓縮；每張最多 24 KB，6 張最多 144 KB。替換、移除和排序在“完成設定”時儲存。

Muse 語音助手可選配置

需要自己的 Muse 賬號、手機 App 和 Gadget SDK Token。儲存後，在裝置應用中開啟 Muse，再用手機 Muse 的“設定 → 裝置 → 開發者模式 → 新增裝置”配對。配對時選擇裝置當前連線的 Wi-Fi。

SDK Token 可在 Muse 官方裝置接入網站 gadgets.muse.ai 申請。建議在連線裝置熱點前準備好。

Muse 專案與完整配置教程 · 需要聯網檢視。Muse 不需要虛擬音效卡或微信輸入法。

正在讀取裝置中的 Muse 配置…

電腦與裝置需在同一區域網，代理需要允許區域網連線。使用電腦代理時，電腦和代理軟體要保持執行。清空 IP 後儲存可切回直連；不會解除已有配對。

僅使用自己的 Token，勿傳送給他人。更換 Token 後需要重新配對。透過裝置熱點配置，頁面不回顯已儲存的金鑰。

Token 和電腦代理設定儲存在這臺裝置，重啟後仍可使用。也可以點下方“儲存並完成設定”一起儲存。
